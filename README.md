# aula11PBE
O projeto Brechó Vintage & Modas (aula 11 da matéria de Programação Back-End 1) consiste em uma API REST desenvolvida em Node.js com o framework Express, integrada a um banco de dados PostgreSQL hospedado no Supabase. O objetivo principal da aplicação é gerenciar e permitir a consulta ao catálogo de vestuário de peças seminovas por meio de rotas específicas: a listagem geral de itens em /roupas, a filtragem de peças por tamanho em /roupas/tamanho-m e a busca individual por identificador em /roupas/:id.

Para a inicialização e organização do ambiente de desenvolvimento no VSCode, foram executados no terminal os comandos de instalação do Express, do Dotenv e da biblioteca cliente do Supabase. A estrutura foi organizada separando as responsabilidades do código, onde o arquivo supabaseClient.js, localizado dentro da pasta config, ficou responsável pela ponte de conexão entre a API e o banco de dados. As credenciais sensíveis do projeto, como a URL da base, a chave da API e a porta do servidor, foram isoladas no arquivo .env.

Antes da criação final da tabela no banco de dados, o servidor foi testado no navegador para validação dos tratamentos de erro da API. Durante os testes, foi possível confirmar o correto funcionamento da resposta HTTP 404 para recursos ou páginas inexistentes, além da resposta 500 para falhas internas de execução no servidor. Sequencialmente, a tabela pecas_vintage foi criada no Supabase via script SQL e populada com dados fictícios de roupas para simulação das consultas.

Após revalidar a integração entre o servidor e o banco de dados, realizou-se o ajuste fino na rota de busca por tamanho. A instrução inicial baseada em .eq('tamanho', 'M') apresentava limitação por ser sensível a maiúsculas e minúsculas. A consulta foi então atualizada para a função .ilike('tamanho', 'm'), garantindo que a requisição em /roupas/tamanho-m retorne corretamente todas as peças cadastradas do tamanho M, independentemente da caixa da letra salva no banco de dados.
